# HTML Studio 可视化编辑器

一个适合本地发布和分享的单文件 HTML 可视化编辑工具。它面向 HTML PPT、AI 生成页面、活动页和轻量作品页的后期微调：上传 HTML，在画布中点击元素，修改文本和样式，再导出干净 HTML。

## 主要能力

- 上传或载入单个 `.html` 文件
- 在安全 iframe 中实时预览 HTML
- 点击画布元素并自动定位源码
- 编辑文本、`src`、`href`、`id`、`class` 和常见 inline style
- 支持斜体、下划线、删除线、对齐、行高、字间距和字体微调
- 支持撤销、重做、刷新渲染和干净导出
- 支持 16:9、4:3、自适应画布，以及 Fit、75%、100%、125% 缩放
- 源码区可折叠，默认突出画布和属性编辑

## 本地使用

```bash
npm start
```

启动后打开：

```text
http://localhost:5178
```

发布前检查：

```bash
npm run check
```

## 使用流程

1. 点击「上传 HTML」导入自己的页面，或点击「示例」快速体验。
2. 在中间画布中点击标题、段落、图片、按钮、卡片等元素。
3. 在右侧属性面板修改内容、颜色、字号、间距、尺寸、圆角、阴影等。
4. 需要精修时展开左侧源码区，选中元素会自动定位源码片段。
5. 点击「导出 HTML」保存最终文件。

## 发布说明

这个项目不依赖构建工具和外部 npm 包，适合直接部署为静态工具，也可以用内置 Node 服务运行。`server/index.js` 只负责静态文件服务和 `/health` 健康检查。
